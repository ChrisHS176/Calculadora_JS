# Calculadora Simple
Dimensión 3

Calculadora básica hecha con HTML, CSS y JavaScript que realiza operaciones aritméticas entre dos números.

## Funcionalidades

- Suma
- Resta
- Multiplicación
- División
- Potencia
- Raíz

## Tecnologías usadas

- HTML5
- CSS
- JavaScript

## Estructura del proyecto
├── index.html # Interfaz de la calculadora
├── estilo.css # Estilos visuales
├── operaciones.js # Lógica de las operaciones
└── README.md # Este archivo
